# Vanilla Weather Dashboard

Search cities and display current weather conditions. Built with vanilla JavaScript.

---

## 🎯 What It Does

- Searches for cities by name
- Fetches weather data from Open-Meteo API (geocoding + weather)
- Displays temperature, condition, humidity, wind speed
- Prevents duplicate city entries
- Persists the city list in localStorage
