# Vanilla Simon Says

A memory game where you repeat a growing pattern of colors. Built with vanilla JavaScript.

---

## 🎯 What It Does

- Generates a random color pattern
- Displays the pattern with flashing panels
- Accepts player input
- Tracks score and high score
- Handles game over states with reset
