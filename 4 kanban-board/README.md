# Vanilla Kanban Board

A task management board with WIP limits, priority levels, and localStorage persistence. Built with vanilla JavaScript.

---

## 🎯 What It Does

- Add tasks to a board with title, description, and priority
- Move tasks between columns (To Do → In Progress → Done)
- Delete tasks
- WIP limit (max 3 tasks in "In Progress") with warning
- Priority levels with color-coded dots (Pending, Urgent, Necessary, Side, Completed)
- Persistent storage (localStorage)
- Two ways to add tasks: main form (first task) and popup form (subsequent tasks)
