# Personal Expense Tracker

An expense management and financial accountability page. Track spending, see patterns, make corrections, and monitor savings. Built with vanilla JavaScript.

---

## 🎯 What It Does

- Add expenses with category, amount, recipient, date, and transaction type
- Credit/debit logic (credit adds, debit subtracts)
- Total per month, highest category, transaction count
- Filter by category, recipient, or amount
- NGN/USD conversion via live exchange rate API
- Green/red indicators for credits and debits
- Persistent storage (localStorage)
