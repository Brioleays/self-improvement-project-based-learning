# Vanilla Counter

A simple counter with increment, decrement, reset, and high score tracking. Built with vanilla JavaScript.

---

## 🎯 What It Does

- Increments and decrements a number (0-20)
- Tracks the highest number reached
- Changes color based on the count (green → yellow → orange → red)
- Persists the high score in localStorage
